## 🚀 焦点头条 (Top Headlines)

### ⚡ 1. OpenAI 与 Anthropic 算力基建债获 3.2 倍超额认购，大模型 ARR 获评“数字公用事业”
* ⚡ **事件详情**：9 月 20 日最新路演纪要显示，全球主权基金与养老金大举认购 OpenAI 与 Anthropic 的首期企业债。认购逻辑在于两家公司企业级 API 与 Agent 席位订阅留存率（NDR）均超过 **135%**，且债务资金专项用于锁定高流动性的英伟达 B200/GB300 算力集群与长期核电/绿电购电协议（PPA）。
* 🧭 **产业传导与影响**：打通了超万亿美元传统固定收益市场向 Frontier AI 实验室直接输血的通道，降低了头部 AI 独角兽对短期 IPO 窗口的依赖。

### 🤖 2. 苹果 iPhone Duo 首周末全球断货，端侧双屏协同 Agent 定义移动新形态
* ⚡ **事件详情**：苹果首款折叠屏手机 iPhone Duo 开售首周末在全球主要市场线上线下同步断货。用户可在左侧屏幕运行实时工作文档或代码仓库，右侧屏幕驻留基于 A20 Pro 端侧 NPU 的系统级视觉操作 Agent，实现跨应用零延迟拖拽与自动填报。
* 🧭 **产业传导与影响**：证明了高端消费电子的换机驱动力已由单纯的光学摄像升级正式切换为“端侧大模型常驻内存带宽与算力密度”。
